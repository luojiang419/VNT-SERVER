# VntService应用程序需求

## 1. 概述
**VntService虚拟组网服务端.exe** 是 VNT 组网服务端的可视化管理工具windows版本。它基于 Python 的 `CustomTkinter` 库构建，充当底层 `vnts.exe` (Rust 核心服务) 的图形化外壳，使用户无需使用命令行即可配置、启动和监控虚拟网络服务。

## 2. 页面布局 (UI Structure)

该程序采用现代化深色主题 (Dark Mode)，窗口默认大小为 700x600，整体布局从上到下分为四个主要区域：

### A. 顶部标题栏 (Header)
*   **左侧**：显示应用标题 **"VNT 组网服务端"**。
*   **右侧**：显示服务运行状态。
    *   **状态指示灯**：圆点符号 `●`（停止时显示灰色，运行时显示绿色）。
    *   **状态文本**：动态显示 "已停止" 或 "运行中"。

### B. 配置滚动区 (Scrollable Config Area)
位于界面中部上方，包含分组排列的参数配置项：

1.  **网络配置**
    *   **监听端口**：vnts 服务的 UDP/TCP 监听端口（默认 `1666`）。
    *   **虚拟网关**：虚拟网络的网关 IP（如 `192.168.188.1`）。
    *   **子网掩码**：虚拟网络的子网掩码（如 `255.255.255.0`）。
    *   **IP 范围展示**：根据输入的网关和掩码，自动计算并显示可用的 IP 地址范围（例如：`IP 范围: 10.10.0.1 - 10.10.0.254`）。

2.  **Web API 配置** (供 Web 后台连接使用)
    *   **API 端口**：RESTful API 服务的端口。
    *   **API 用户名/密码**：用于 API 访问的身份认证信息。

4.  **安全配置**
    *   **Token 白名单**：文本输入框，支持逗号分隔多个 Token。

### C. 监控与日志区 (Logs & Users)
位于界面中部下方，分为左右两栏布局：
运行状态信息显示和在线用户显示
    *   **标题**：动态显示当前在线设备数量（如 `在线用户 (3)`）。
    *   **列表视图**：使用表格展示每台在线设备的 **名称** 和 **虚拟IP**。

### D. 底部操作栏 (Footer)
*   **"保存配置" 按钮**：将当前界面上的所有设置保存到 `server_config.json` 文件中。
*   **"启动服务" / "停止服务" 按钮**：核心控制按钮。点击启动后，按钮变为红色并显示"停止服务"；点击停止后，恢复绿色并显示"启动服务"。

## 3. 核心功能 (Features)

### 1. 服务生命周期管理
*   **多进程编排**：点击启动时，程序会在后台同时启动两个子进程：
    1.  **核心服务 (`vnts.exe`)**：Rust 编写的高性能网络转发引擎。
    2.  **Web 前端服务 (`web_server.py`)**：提供基于浏览器的可视化拓扑管理界面。
*   **异常监控**：如果底层进程意外退出，GUI 会自动感知并更新状态为“已停止”。

### 2. 智能化配置体验
*   **动态计算**：输入网关和掩码时，程序会实时计算网络范围，帮助用户避免配置无效的子网。
*   **参数映射**：将用户友好的图形界面输入自动转换为复杂的命令行参数（如 `-p`, `--white-token`, `-f` 等）传递给底层程序。
*   **配置持久化**：所有配置项均自动读取和保存至本地 JSON 文件，重启程序后配置不丢失。

### 3. 实时监控系统
*   **日志重定向**：解决了控制台程序窗口过多干扰用户的问题，将日志集成在 GUI 内部展示。
*   **自动轮询**：程序内置定时器，每 **5秒** 自动调用本地 API 接口获取最新设备列表，实时刷新在线用户状态。

### 4. 系统集成
*   **系统托盘支持**：点击窗口关闭按钮 (X) 时，程序不会直接退出，而是最小化到 Windows 系统托盘区，确保服务端在后台持续稳定运行。
*   **托盘菜单**：右键托盘图标提供“显示窗口”和“退出”选项。

## 4. 技术栈
*   **语言**: Python 3.x
*   **GUI 框架**: CustomTkinter (基于 Tkinter 的现代化 UI 库)
*   **进程管理**: subprocess
*   **系统托盘**: pystray
*   **图像处理**: PIL (Pillow)
